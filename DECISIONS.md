# Keputusan

Log **append-only**. **FAKTA** = terkonfirmasi user. **ASUMSI** = sementara; naik jadi keputusan saat dikonfirmasi.
Tiap keputusan punya **ID `D-00x`** (biar bisa ditunjuk dari berkas fitur tanpa ditulis ulang).
Format entri: `D-00x · tanggal · konteks singkat · keputusan · alasan`.
